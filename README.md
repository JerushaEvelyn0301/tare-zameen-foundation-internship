# Tare Zameen Foundation – Internship Project

## Overview

This repository contains the technical work completed during my Community Development Internship at Tare Zameen Foundation.

The project focuses on organizing fundraising data using database concepts and structured data analysis.

## Project Objective

The objective was to structure donor and contribution information in a systematic manner and use database concepts to support accurate tracking and reporting.

## Technical Work

- Designed a relational database structure for donor and contribution records
- Organized fundraising data
- Applied DBMS concepts
- Used SQL queries for data analysis and reporting
- Performed aggregate analysis such as total, average, maximum and minimum contributions

## Database Structure

The project uses two main entities:

- **Donors** – stores donor information
- **Contributions** – stores contribution records linked to donors
